# BaGetter fork documentation

[← Project README](../readme.md) · [Deutsch](../README.de.md)

This is the documentation entry point for **Cenn0/BaGetter**, an independently maintained fork of [BaGetter](https://github.com/bagetter/BaGetter). Upstream releases, images and documentation do **not** automatically cover changes made in this fork.

| Task | Guide |
| --- | --- |
| Run locally | [Quick start](../readme.md#quick-start) |
| Configure and operate persistent storage, backup and recovery | [Operations](OPERATIONS.md) |
| Set up and test the optional nuget.org read-through mirror | [Mirror guide](MIRROR.md) |
| Understand the implementation priorities and acceptance gates | [Fork roadmap](../ROADMAP.md) |
| Contribute | [Contributing](../CONTRIBUTING.md) · [Code of conduct](../CODE_OF_CONDUCT.md) |
| Report vulnerabilities privately | [Security](../SECURITY.md) |
| Explore upstream-oriented installation documentation | [Docusaurus reference](docs/Index.md) |

**Supported in source** does not mean **fully verified** or **production-approved**. Selected real nuget.org smoke tests are described in [MIRROR.md](MIRROR.md). Full proxy behavior, multi-instance correctness and production deployment remain separately qualified.

The [website development guide](readme.md) describes the Docusaurus build; it is not the operator guide for this fork.
